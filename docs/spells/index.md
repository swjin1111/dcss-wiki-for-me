# 마법 (Spells)

> 기준: DCSS 0.34.1

## 기본 규칙
- 마법의 **MP 소모 = 마법 레벨**이다. (Spellmotor gizmo, Efficient Magic 돌연변이 등으로 감소)
- **Power cap(위력 상한)**: Spell power(마법 위력)가 이 값을 넘어도 효과는 더 오르지 않는다.
- 마법 하나가 여러 학파에 속하면, 실패율과 Spell power에 모든 학파 스킬이 반영된다.
