# 아티팩트 속성 (Artefact Properties)

> 기준: DCSS 0.34.1 · [아이템 목록으로](index.md)

랜덤 아티팩트(randart)는 무작위로 정해진 속성을 가진 장비다. 이 문서는 randart에 붙을 수 있는 속성과 생성 규칙을 정리한다. 언랜드 아티팩트도 같은 속성 체계를 쓰지만, 고유 효과는 언랜드 문서(예정)에서 다룬다.

- 아티팩트가 될 수 있는 것: 무기, 방어구, 반지·목걸이, 지팡이(Staff), 탈리스만. (마법서는 별도 체계)
- 아티팩트는 인챈트 스크롤로 강화할 수 없다(Mountain Dwarf의 randart 예외). → [아이템 개요](index.md#인챈트-enchantment-n)

---

## 생성 확률 (간략)

| 아이템 | 아티팩트 확률 (L = 아이템 레벨) |
|---|---|
| 무기, 방어구, 반지·목걸이 | `(101 + 3L) / 4000` (L = 0이면 0). 무기·방어구는 그중 1/20이 언랜드 시도 |
| 지팡이 | `(101 + 3L) / 8000`. 별도로 1/100 확률로 언랜드 지팡이 시도 |
| 탈리스만 | `max(0, L − (등급−1)×6) × 2.5 + 5` % (여기서 L은 최대 35). 낮은 등급 탈리스만일수록 아티팩트가 훨씬 흔하다 |

## 속성 개수 정하기
randart는 아래 순서로 속성 개수를 정한다.

1. **품질(quality)** = 1 + (21% 확률 시행 6번 중 성공 수). 범위 1~7, 평균 약 2.3.
2. **나쁜 속성 수** = 21% 확률 시행 2번 중 성공 수. 범위 0~2.
3. **좋은 속성 수** = 품질 + 나쁜 속성 수. **나쁜 속성 하나마다 좋은 속성이 하나 더 붙는다.**
4. **서로 다른 속성은 최대 4개**(5% 확률로 5개, 드물게 6개). 넘치는 좋은 속성 몫은 이미 붙은 속성의 수치를 올리는 데 쓰인다.

같은 속성이 여러 번 뽑히면 수치가 쌓일 수 있다(아래 "중첩" 참고). 나쁜 속성은 이미 좋은 값이 붙은 속성에는 붙지 않는다.

### 기본 부가 사항
- **무기 randart는 항상 브랜드가 있다.** ([브랜드 가중치](#무기-randart의-브랜드))
- **방어구 randart**: scarf와 orb는 항상 에고, 그 밖의 방어구는 50% 확률로 일반 에고 표에서 에고를 굴린다. 에고와 같은 효과의 속성이 있으면 그 에고는 속성으로 대체된다.
- **인챈트**:
  - 무기: 평균 약 +5 (최소 0~1, 최대 +12).
  - 방어구: 1/5 확률로 +0, 아니면 0~(스크롤 상한) 사이 무작위.
  - **Bane 속성이 붙으면 보상으로** 무기 인챈트 +2~4(최대 +12), 방어구 인챈트도 추가로 높아진다.

"가중치"는 속성을 고를 때의 상대 비중이다(전체 합 약 1000). 가중치 0인 속성은 randart에는 나오지 않고, 언랜드나 아이템 고유 속성으로만 존재한다.

### 나쁜 속성
| 속성 | 가중치 | 효과 | 붙을 수 있는 장비 |
|---|---|---|---|
| \*Noise | 30 | 휘두를 때 큰 소음을 낼 수 있음 | **근접 무기만** |
| \*Rage | 30 | 근접 공격 시 20% 확률로 광폭화 | **근접 무기만** |
| −Tele | 25 | 대부분의 순간이동 차단 | 방어구, 목걸이, 탈리스만 (+Blink와 충돌) |
| ^Contam | 20 | **해제할 때** 마법 오염 1200 (위험 단계 이상) | 탈리스만 제외 |
| ^Drain | 25 | **해제할 때** 최대 HP Drain | 탈리스만 제외 |
| \*Corrode | 25 | 피해를 받을 때마다 3% 확률로 부식 (여러 개면 개수 × 3%) | 전부 (rCorr와 충돌) |
| \*Slow | 25 | 피해를 받을 때마다 1% 확률로 10~14턴 감속 (개수만큼 증가) | 전부 |
| \*Silence | 25 | 피해를 받을 때마다 1% 확률로 4~10턴 침묵 (개수만큼 증가) | 방어구, 목걸이 (Mana Regeneration 목걸이 제외), 탈리스만. 학파 강화와 같이 붙지 않음 |
| ^Fragile | 30 | **해제하면 파괴** | 무기, 지팡이, 목걸이 (방어구·반지·탈리스만 제외) |
| Bane | 20 | 장착할 때 무작위 Bane(저주성 상태) 하나를 얻음 | 무기, 방어구만 |

- 기호 규칙: `*`는 장착 중 계속 위험이 있는 것, `^`는 장착·해제 순간에 대가가 있는 것이다.
- 나쁜 속성이 있으면 그만큼 좋은 속성이 하나 더 붙는다. 반대로 말하면 나쁜 속성 2개짜리 randart는 좋은 속성 몫이 2개 더 있다.
- Bane의 종류와 효과는 돌연변이 & 파멸 문서(예정)에서 다룬다.

### randart에는 나오지 않는 속성 (가중치 0)
언랜드 아티팩트나 아이템 고유 속성에만 쓰인다.

AC, EV, SH, HP, Clar(Clarity), RMsl(투사체 방어), rMut(돌연변이 저항), −Cast(주문 시전 불가), Acrobat, RegenMP(마나 재생), Wiz(Wizardry), BAcc·BDam(기본 명중·데미지), Delay, nupgr

## 무기 randart의 브랜드
일반 무기에는 안 나오는 Chaos, Reaping, Penetration도 randart에는 나올 수 있다.

### 근접 무기 (일반)
| 브랜드 | 가중치 |
|---|---|
| Flaming / Freezing | 각 47 |
| 무기 계열 전용 브랜드 (Devious, Valour, Concussion, Sundering, Entangling, Rebuke) | 35 |
| Heavy / Venom / Draining | 각 26 |
| Holy Wrath / Electrocution / Speed / Vampirism / Pain / Antimagic / Protection / Spectral | 각 13 |
| Reaping | 6 |
| Distortion / Chaos | 각 3 |

그 무기에 맞지 않는 브랜드가 뽑히면 다시 굴린다.

### 원거리 무기
| 브랜드 | 가중치 |
|---|---|
| Draining / Heavy / Flaming / Freezing | 각 8 |
| Electrocution | 4 |
| Speed | 3 |
| Antimagic / Chaos | 각 2 |
| Holy Wrath | 1 |

- **크로스보우는 1/6 확률로 Penetration으로 바뀐다.**

### 그 밖
- **악마 무기**(demon whip, blade, trident): 7/9 확률로 Draining, Flaming, Freezing, Electrocution, Vampirism, Pain, Venom 중 하나(균등). 나머지 2/9는 일반 근접 표.
- **TSO 축복 무기**: 항상 Holy Wrath.
