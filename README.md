# DCSS 개인용 위키 (dcss-wiki-for-me)

Dungeon Crawl Stone Soup **stable 0.34.1** 소스코드를 직접 읽고 정리한 개인용 위키.
기존 웹 위키의 누락·구버전 정보를 피하고, Claude·Gemini 같은 LLM에 첨부해서 질문할 수 있게 만드는 것이 목적.

- 기준 소스: [crawl/crawl](https://github.com/crawl/crawl) 태그 `0.34.1` (커밋 `1eebc1a`)
- 작성 규칙: [CONVENTIONS.md](CONVENTIONS.md)
- 작업 계획: [ROADMAP.md](ROADMAP.md)
